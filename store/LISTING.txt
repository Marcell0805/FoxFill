# FoxFill — Chrome Web Store listing copy

## Summary (already in manifest / tagline field)
Your details. Less hassle. Privacy-first form filling from a local profile.

## Description (paste into Description*)

FoxFill fills web forms from a profile that lives only on your device.

Save your personal and address details once, then on any form: Scan → Review → Fill. FoxFill shows what it will enter, highlights matched fields on the page, and skips sections that look sensitive (like bank or emergency contacts).

HOW IT WORKS
1. Add your details under Personal and Address (or open Full settings for a roomier editor).
2. Open a webpage with a form and click Scan Form.
3. Review ready fields, tick anything marked for review, then Fill.
4. Optional on-page overlay marks certain (green) vs review (yellow) matches.

WHY FOXFILL
• Local first — profiles stay in your browser; no account and no cloud sync.
• You stay in control — review before fill; no auto-submit; empty fields only.
• Multi-profile — keep Personal, Work, or other profiles and switch anytime.
• Smart matching — names, email, phone, ID, passport, address, DOB, and more.
• Custom fields — add your own labels and aliases for site-specific forms.
• Optional encryption — lock profiles with a passphrase (AES-GCM on this device).
• Privacy-minded fill — skips bank/emergency-style sections; leaves area-code boxes empty.

PERMISSIONS (WHY WE ASK)
• storage — save your profiles on this device (optionally encrypted).
• activeTab — access the page you open when you scan.
• scripting — run the scanner and filler after you click Scan, Fill, or the optional page button.
• Optional site access — only if you turn on the Page fill button; used to show the side icon and fill when you click it.

The Page fill button is off by default. FoxFill does not send your profile to a server.

Made for everyday forms: quotes, registrations, contact pages, and more — less retyping, same privacy mindset.

## Privacy practices (Chrome Web Store)

### Single purpose description*
FoxFill fills web forms from a user-managed profile stored only on the local device. Users scan a page, review matched fields, and choose what to fill. An optional Page fill button can fill confident matches after an explicit click.

### storage justification*
FoxFill stores the user’s form-fill profiles (personal/address details, custom fields, and optional encryption settings) in chrome.storage.local on this device so details can be reused across form scans. No profile data is sent to a remote server.

### activeTab justification*
FoxFill needs temporary access to the active tab when the user opens the extension and clicks Scan or Fill, so it can read form fields on that page and write approved values into empty inputs. Access is only used after an explicit user action on the current tab.

### scripting justification*
FoxFill injects its scanner, matcher, and filler scripts when the user clicks Scan or Fill in the popup, or clicks the optional Page fill button on a page. Scripts detect form fields, show review highlights when scanning from the popup, and fill selected empty fields. FoxFill does not auto-fill on page load without a user click.

### Host permission justification* (optional — only if declared / granted)
FoxFill may request optional access to http/https pages only when the user turns on the Page fill button. That access is used to show a small on-page control and, after the user clicks it, to scan the page and fill confidently matched empty fields from the local profile. Profiles are never sent to a remote server. The feature is off by default; denying site access keeps popup Scan/Fill working via activeTab.
